# ✨ Buchstaben Lernen

Eine einfache Web-App zum Lesenlernen für Kinder. Buchstaben und Silben werden einzeln auf einer grossen Karte angezeigt — das Kind liest laut vor, tippt auf die Karte und kommt zum nächsten Buchstaben.

**→ [jonasprobst.github.io/lesenlernen](https://jonasprobst.github.io/lesenlernen/)**

---

## Benutzung

Die App läuft direkt im Browser, ohne Installation. Einfach die Seite öffnen, Level wählen und loslegen.

**Steuerung**
- Karte antippen / klicken → nächster Buchstabe
- Play/Pause-Button → automatischen Ablauf starten oder pausieren
- Leertaste → Play/Pause (Tastatur)
- Pfeil rechts → nächster Buchstabe (Tastatur)

---

## Level

### Level 1 — Buchstaben
Einzelne Buchstaben von A–Z werden angezeigt. Zwischen den Buchstaben erscheinen kurze Einblendungen (Farben oder Bilder) als visuelle Pause.

### Level 2 — Silben
Konsonant + Vokal Kombinationen (MA, ME, MI, KA, BI, …). Ideal für den nächsten Schritt nach den einzelnen Buchstaben.

---

## Einstellungen

Die Einstellungen sind pro Level und über das ⚙️-Symbol während des Spiels erreichbar.

| Einstellung | Beschreibung |
|---|---|
| **Geschwindigkeit** | Wie lange jeder Buchstabe angezeigt wird (0.6s – 4s) |
| **Groß / Klein** | `ABC` Grossbuchstaben · `abc` Kleinbuchstaben · `Gemischt` zufällig gemischt |
| **Buchstaben / Silben** | Welche Buchstaben oder Konsonanten/Vokale aktiv sind |
| **Sessionlänge** | Wie viele Buchstaben pro Durchgang gezeigt werden (10 / 20 / 50 / Alle) |
| **Einblendung** | Was zwischen Buchstaben erscheint: Farbe · Objekte · Tiere · Monster |
| **Darstellung** | 🌙 Dunkel · ☀️ Hell · 🎒 Schule |

### 🎒 Schulmodus
Speziell für den Unterricht: ruhiger weisser Hintergrund, keine Animationen, kein Fortschrittsbalken. Der Fokus liegt vollständig auf dem Buchstaben. Farbkarten verwenden dezente Primärfarben.
